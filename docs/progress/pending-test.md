# 待测试

## 画布菜单与素材栏

- 空白处右键或双击打开添加菜单，支持已有节点类型、上传与素材入口。菜单固定屏幕尺寸，自动避让边缘，支持方向键和 Escape；创建节点仍使用点击处的画布坐标。
- 画布工具栏、添加菜单、助手的素材入口统一打开左侧悬浮圆角面板，不再弹出素材选择窗口。图层、提示词导航移至底部，保留侧栏宽度保存方式。
- 素材栏区分个人 / 公共来源，搜索常驻，媒体类型与标签收在筛选按钮内。分类文件夹原地展开，灰色立体文件夹图标；空目录只显示一行提示，支持多目录展开与全部素材视图。使用既有 category 字段，不是新增的多级文件夹或团队权限系统。
- 素材卡片展示名称、类型和预览，支持点击插入及原生拖拽到画布；未改素材存储、模型配置或生成接口。
- 素材内容区可滚动，筛选浮层在较矮窗口内可滚动；提供加载、空列表、预览失败、公共分类与素材加载失败重试反馈。公共标签来自公共素材接口，切换来源清空不通用的已选标签。
- 进入画布默认中性深色主题，手动浅色切换仍可使用；背景只保留点阵和纯色，不再显示方格线。已有网格背景打开后显示点阵，节点和业务连线保留。
- Mac 双指滑动/普通滚轮改为双轴平移；捏合或 Cmd / Ctrl + 滚轮缩放，保留约 20% / 100 单位输入的响应、鼠标位置锚点与 5%–500% 范围。连续同帧事件累积处理，不抢占输入框/控件的独立滚动；两处快捷键提示同步更新。真实触控板的手感仍需人工体验。
- 多选未编组节点后显示整体选区框，可点击“编为一组”，或从右侧“编组并连接所选节点”连接点直接拖出连线并自动编组。组节点保留输出点，支持用一条组连线接已有节点或在空白处新建下游节点；原节点独立保留，沿用现有不支持嵌套编组的限制。
- 整组输入展开为真实组员资源供生成、@引用、参考缩略图、视频首尾帧与高级资源选项使用，重复引用去重。取消组员参考时确认断开整组连线，不删除组或素材；可撤销，保存后可重新打开。

验证入口：`web/tests/canvas-ui.e2e.cjs`。使用本地开发服务和独立匿名浏览器上下文，不执行全量构建、不调用付费模型。仍请使用自己的图片、视频和已有项目确认预览、生成结果保存与日常操作习惯。
