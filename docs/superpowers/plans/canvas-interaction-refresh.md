## 纠正 Mac 手势，并支持整组选区连线

### 依据与设计

- 用户反馈普通双指滑动被错误用于缩放；[TapNow 官方画布说明](https://docs.tapnow.ai/zh/docs/canvas/explore-the-canvas)明确普通滚轮/双指滑动平移、捏合或 Cmd + 滚轮缩放。[MDN wheel 事件说明](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)说明浏览器捏合缩放通过带 ctrlKey 的 wheel 事件传递。以上为官方文档依据，不是对用户登录页面的现场实测。
- 原因：React onWheel 无条件使用 deltaY 计算缩放；document capture 仅处理 Ctrl-wheel。修复为普通事件平移，Ctrl / Cmd 事件才缩放，共用输入框与 no-zoom 排除规则。用即时 viewport ref 累积同帧高频事件，避免触控板掉步。
- 用户补充多选后希望整体连下游。复用现有 Group 与 groupId，选区显示编组按钮和整体输出点；拖出时自动编组，Group 节点补输出连接点，连接规则允许 Group 指向组外普通/配置节点。禁止连接回自身组员，不引入嵌套编组，不合并或删除原素材。
- 单条组连线在资源读取时展开组员，供生成和引用界面复用；去重并排除目标自身。独立审查指出原参考缩略图/视频资源选项仍只读直接节点，已统一使用资源展开函数。点击组员参考的移除按钮时确认断开整组，保留节点，不做隐式部分拆线。
